# TaskFlow

1. Create a Cloudant database named `taskflow-db` (non-partitioned).
2. Set environment variables: CLOUDANT_URL, CLOUDANT_APIKEY (optional: CLOUDANT_DB, PORT).
3. `npm install` then `npm start`, open http://localhost:3000
4. Push to GitHub and deploy (IBM Code Engine, Render, etc.) with start command `npm start`.
